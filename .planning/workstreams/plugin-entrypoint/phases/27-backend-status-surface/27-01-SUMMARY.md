## Decisions Made
- HubSpot's own credential-health entry is derived from the `HS Requested Search (Companies)` probe rather than adding a fifth dedicated health-check node — all four searches share the same credential, so a refusal on any one of them is the same finding; using the first one in the chain avoids a redundant probe.
- `Build Status` is a new terminal node (not a rename of `Build Credit Status`) so `Build Credit Status`'s existing credit-assembly logic and its own structural tests stay valid unchanged; the new node only reads it by name via the same guarded `nodeAll` idiom.
