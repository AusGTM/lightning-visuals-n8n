<objective>
Thread the envelope-level `mode` onto every row, make the two terminal marker nodes carry
the row they terminate, and refuse an oversize `events` array whole.

Purpose: 36-RESEARCH.md §D.1 found what 36-CONTEXT.md §7 step 4 assumes but does not state —
`parseWebhookBody()` has NO `mode` extraction today, so an envelope-level `mode` physically
cannot reach a row. Separately, `Skip (NoOp)` and `Unsupported Object Type` are `Set` nodes,
and a `Set v3.4` emits only its assigned key: a HIGH-matched fresh row would return an
uncorrelatable reply with no `row_id`. And PREVIEW-03's server half is the refusal — an
oversize batch is refused whole, never truncated (the D-15 principle the list lane already
honours).

Output: `mode` on every row, two row-carrying terminals with their waivers retired, and a
reasoned refusal for an events array that is too large or empty.
</objective>
