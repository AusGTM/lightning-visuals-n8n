    Four blocks, in the order the operator needs them to decide: what is being enriched (the exact

    line that could be read as "you have enough" when the answer is unknown; that sentence is the whole

    backend is unreachable is not a guard.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend status response → operator-facing prose | Untrusted backend content becomes text an operator makes a spending decision on |
| preview → approval | Everything the operator consents to is bounded by what this block showed |
| skill conversation → config secret | The secret must never cross into the conversation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-05 | Tampering | rendered balance line | critical | mitigate | The unreadable line states headroom could not be confirmed; a test asserts an unreadable balance's rendered text carries no zero figure for that provider, and that a readable zero renders differently |
| T-25-26 | Repudiation | provider selection display | high | mitigate | The resolved selection is rendered on every preview including the full-waterfall and none cases, so a permissive default can never take effect unseen (D-06) |
| T-25-27 | Repudiation | fabricated record count for a list | high | mitigate | The list preview shows the identifier and states the count is backend-resolved; a test asserts no numeric count appears (D-02) |
| T-25-22 | Denial of Service | preview when the status endpoint is down | medium | mitigate | The preview renders in full with every balance unknown rather than failing, so the operator still sees the estimate, the selection and the chunk plan |
| T-25-17 | Information Disclosure | skill conversation | high | mitigate | The skill relays the config gate's refusal as-is, never shows or asks for a secret, and never surfaces a raw socket or parser error |
| T-25-01 | Elevation of Privilege | skill arming step | critical | mitigate | Arming is stated as off, named as conversation-scoped, written nowhere, and passed as a flag for one dispatch — Phase 23's D-11 unchanged |
