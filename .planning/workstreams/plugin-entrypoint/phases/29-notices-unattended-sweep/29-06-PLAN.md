<objective>
Ship the sweep: the skill the routine invokes, the routine template the admin installs, the docs that
make the two-part setup explicit, and the one live end-to-end gate that proves the whole path works
on a real backend.

29-RESEARCH.md flagged the seam this plan closes. The sweep's *logic* lives under
`operator-claude-plugin/` per PLUGIN-04, but its *trigger* is a Scheduled routine living in a
machine-local directory outside the plugin's packaging. Installing the sweep is therefore two steps —
install the plugin, then author the routine — and a phase that ships the code without documenting the
second step ships a sweep that never fires.

The live gate matters as much as the code. Everything before this point was verified against
fixtures. NOTICE-03's claim is about a notification arriving with nobody watching, and no fixture can
demonstrate that.

Purpose: the sweep exists in the operator's world, not only in the test suite.
Output: the skill, the routine template, the setup documentation, and an observed live notice.
</objective>

       learns to ignore.

       the review-backlog threshold: set it below the current real backlog count so the condition
       fires on real data without changing anything in the backend. Do **not** manufacture a
       condition by breaking a credential or arming the backend — the sweep is being tested, not the
       backend's failure modes.

       the observed length ceiling; it states the cause in plain language; it states whether the
       operator or an admin can act; and it contains no instruction to run a command or open a
       terminal.

    6. Confirm, from n8n's own execution history and the provider credit balances, that the sweep's
       firings performed **no** write and consumed **no** provider credits. This is the observable
       counterpart to the import-graph guard: the guard proves no code path exists, this proves none

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scheduled routine → plugin capability | An unattended context invoking plugin capability with no operator present to catch a wrong action |
| shipped skill body → capability surface | A clean module graph invoked by a wide skill body still violates NOTICE-05 |
