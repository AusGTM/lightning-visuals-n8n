<objective>
Move config resolution off the versioned install directory and onto a version-independent
durable home, and pin the whole resolution order at the CLI entrypoint against an isolated
plugin root with a fake `HOME`.

This is the phase's tracer: one path — durable home → shared resolver → `config_gate` →
`config_gate.py`'s `__main__` → a subprocess test — wired end to end and committed, before
the sibling migration (33-02) or the dashboard pointer (33-03) build out from it.

Resolution steps 1–4 land here (explicit arg → `LV_OPERATOR_CONFIG` → durable home →
legacy same-install). Step 5, the one-time sibling scan and migration, is 33-02's whole
subject and is deliberately absent from this plan.

Purpose: PLUGIN-02 — config setup becomes a genuinely one-time operator step, because the
file no longer lives inside a directory that a plugin update abandons.
Output: `scripts/durable_paths.py`, a `config_gate` that resolves through it, an
`init_check` that reports the same resolved path, and an extended `_run_cli` harness.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin process → operator's home directory | The plugin reads and (from 33-02) writes a plaintext file holding `webhook_secret` and `n8n_api_key` at a path derived from `$HOME` and an environment variable |
| test subprocess → real operator config | A test harness that leaks the real `HOME` reads live credentials into a test run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-33-01 | Information Disclosure | `_run_cli` subprocess env | high | mitigate | Build the subprocess `env` from a literal dict carrying only `PATH` and a `tmp_path` `HOME`; never spread `os.environ`. Task 1. |
| T-33-02 | Information Disclosure | `config_gate` refusal messages | high | mitigate | The sentinel-secret assertion in Task 2 checks both `stdout` and `stderr` on a refusal branch, generalizing the existing function-layer guard to the process layer. |
| T-33-03 | Tampering | `LV_OPERATOR_CONFIG` | low | accept | An attacker who can set this operator's environment variables already has code execution as that operator; the variable is an intentional admin escape hatch (D-1, contract 2). |
| T-33-04 | Denial of Service | `durable_dir()` when `HOME` is unset | low | mitigate | `Path.home()` falls back to the `pwd` database on POSIX rather than raising; step 4 remains the terminal fallback so resolution always returns a path. |
