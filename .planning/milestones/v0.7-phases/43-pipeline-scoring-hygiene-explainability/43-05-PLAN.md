<objective>
Deploy the regenerated workflow content from 43-01 to n8n Cloud, bounce the affected
workflows so the running instances actually pick it up, and prove the deployed content is
disarmed.

Purpose: PIPE-01 and PIPE-02's fixes are compiled into `n8n/*.json` by 43-01, but a workflow
that has not been deployed and bounced is a fix nobody is running.

disarmed defaults. Phase 41's live import currently has an arm window open on 66 real customer
records; deploying while it is open silently closes that window mid-run, leaving the remaining
records looking processed while writing nothing. The precondition on Task 1 is that gate, and
it is not a formality.

Output: a deploy-and-bounce record appended to `43-LIVE-EVIDENCE.md`, and the phase's closing
regression verdict.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local built JSON -> n8n Cloud stored workflow | A deploy replaces production orchestration content wholesale |
| n8n stored content -> n8n running instance | These diverge until a bounce; a deploy without one changes nothing observable |
| This phase's deploy -> Phase 41's in-flight armed run | An unrelated phase's live state is destroyable by this action |
