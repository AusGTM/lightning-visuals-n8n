<objective>
Close the phase: prove the whole chain end to end, build the backfill mechanism Phase 41 will run at
scale, and produce the committed parity verdict that makes PARITY-01 an artifact rather than a claim.

ENGINE-01 is the phase's headline assertion and it can only be made now, once all five components
exist (40-04), both mapper flows read canonical inputs (40-05) and the tier ladder is correct
(40-06). Today that same record grades 60/B off native inputs; the target is 80/A off canonical ones.

The backfill exists because HubSpot's property defaults stamp new records only. The 712 existing
companies have no components at all, so their `lv_icp_fit_score` is null and WF1 never fires. D-10
picks the mechanism deliberately: compute each record's five component scores from its own current
canonical inputs and batch PATCH them, which makes the calculated sum recompute and WF1 fire — rather
than relying on a same-value re-enrollment behaviour nobody has verified. D-09 scopes this phase to
proving that mechanism on a handful of records; the portfolio-wide run is Phase 41, after enrichment
has populated inputs so the scores land meaningful instead of mass-Unscored.

Purpose: a mechanism proven on five records is a mechanism; a mechanism proven on zero is a plan.
Output: one client helper, one gated backfill script, one committed parity verdict.
</objective>
