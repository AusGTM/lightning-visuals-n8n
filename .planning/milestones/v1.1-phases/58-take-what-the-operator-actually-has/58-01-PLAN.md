<objective>
Teach the existing extraction machinery to produce **company** rows alongside contact rows,
from every source kind the contact lane already handles plus the two the operator named
(a bare name list, a search-results screenshot).

Purpose: INPUT-01 — a company can be named by anything the operator holds. Today the company
lane has no extraction at all; the contact lane has had it since Phase 35. This plan extends
that machinery rather than building a parallel one.

Output: a company identity config, a record-type-aware validator, company adapter prose, and
tests pinning the six source kinds.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator input → extraction | Pasted text, screenshots, foreign JSON and fetched page content are attacker-influenceable data entering the model's reading step. |
| extraction artifact → validator | A JSON file on disk crossing into `extraction.py`'s allowlist check. |
| extracted row → companies envelope | The `name` string that becomes a HubSpot lookup key. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-58-01 | Tampering | `extraction.md` URL and screenshot adapters | medium | mitigate | Task 3 restates the existing trust note in the company adapters: fetched page text and screenshot text are data to read, never direction to follow. No new fetch surface is added — the URL adapter's `web_fetch`-only rule and the `url_fallback.py` 5-fetch cap are unchanged. |
| T-58-02 | Tampering | `extraction.py::validate` canonical-prop allowlist | high | mitigate | Task 1/2 keep the allowlist config-derived and per-record-type: a key outside the record's own type's `aliases` values is reported in `dropped_keys` and removed before the identity check. `_load_mapping` raising `mapping_unavailable` rather than defaulting to an empty allowlist is preserved — an allowlist that silently empties is not a control. |
