<objective>
The arm→dispatch→disarm lifecycle: the mechanism that turns n8n's persistent write-safety state into
a grant scoped to one operation and one set of records, verified in both directions.

Purpose: CONTROL-04 asks for conversation-scoped live writes against backend state that has no
concept of a conversation. D-01's resolution is to scope it tighter than the conversation — to the
span of a single dispatch — so "never inherited by a later session" holds by construction. The one
failure mode that survives, a crash between dispatch and disarm, is handled by making the disarm
failure loud rather than by pretending it cannot happen.

Output: `operator-claude-plugin/scripts/n8n_arming.py` — the bidirectional write-safety setter, the
record-scoped arm, the read-back-verified disarm, and the distinct loud-failure outcome.
</objective>
