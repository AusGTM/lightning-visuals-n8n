<objective>
Build the MEDIUM match lane: `lastname EQ` + `company CONTAINS_TOKEN`, re-verified by value,
returned as a proposal — plus the gate rule that stops an unmatchable row burning three
provider calls.

Purpose: a contact row with firstname + lastname + company but no email dead-ends completely
and silently today (36-CONTEXT.md §2, measured live on 9 Gold Coast Turf Club directors). The
enrichment lane already accepts a raw row and already builds name+company identity keys; what
is missing is a HubSpot search that can find an existing record without an email, and an
honest verdict when it cannot.

Output: four new nodes hanging off `IF Bare Event`'s false edge, a credential-map entry, a
`match` verdict on every row, and an `action: "skip"` for rows nothing can match.
</objective>
