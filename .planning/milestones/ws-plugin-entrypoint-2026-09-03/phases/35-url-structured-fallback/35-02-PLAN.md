<objective>
Pin the fences. Everything in 35-01 is behaviour; this plan is the set of tests that make each
bound fail loudly if a later edit removes it, plus the provenance rule that makes a wp-json-sourced
row auditable.

Purpose: the two halves of this contract — instructions in `extraction.md`, logic in
`url_fallback.py` — have no compiler between them. The same hand-maintained-drift class that made
Phase 34 write `columnMapAliasParity.test.mjs` applies here: the cap the operator is quoted and the
cap the module enforces agree by hand unless a test makes them agree by construction.

Output: provenance wording in `extraction.md`'s URL adapter, an import-set guard on
`url_fallback.py`, and contract assertions in `test_extraction_contract.py`.
</objective>
