## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repo → n8n Cloud | a deploy replaces a live workflow body; an armed body deployed by accident would write to production HubSpot |
| `.env` → process environment | credentials are loaded in-process only; never echoed, never sourced from a shell |
| execution runData → transcript and repo | runData embeds the webhook shared secret and the caller IP verbatim |
| plugin version → operator's marketplace clone | the bump is what makes the fixes reachable by the operator |
