against an exact-set predicate, compute all five component scores from the Python oracle, shape
the batch payload, and emit a budget-bounded plan the operator can read before deciding — with

size, under which write window, and at what stated cost, **before** invoking anything. Producing

class that let a stale 18-record census survive two phases.

`scripts/backfill_seed_company_scores.py`; offline test coverage for both.
