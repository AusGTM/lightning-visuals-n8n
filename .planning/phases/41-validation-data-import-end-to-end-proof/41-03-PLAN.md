**F4 — this plan is not autonomous and must not pretend to be.** Two hard limits shape it:

1. `.env` is permission-blocked to both Read and Bash in this environment, and arming live writes
   is operator-only by D-06 and by the n8n-deploy permission boundary. Every command below that
   needs a token, an n8n credential or `ALLOW_N8N_ARM` is **handed to the operator verbatim**, not
   executed. Where a value must come from `.env`, the command is given `!`-prefixed so the
   operator's shell loads it.
2. The run is hours of wall-clock, not one session. Five canary records cross at least one 15-minute
   poller tick, and roughly 82% of each record's enrichment is two sequential Anthropic calls. The
   executor's job in Task 3 is to prepare, hand over, wait, then read and judge the result — not to
   drive it continuously.

An executor that treats any of the three tasks below as a script to run will stall. Task 2 is a
blocking operator sitting; Task 3 is prepare-hand-over-evaluate.
</execution_boundary>
