the one case where it did not come from the portal say so out loud.

the loader that carries the evidenced flag through, and the two documentation amendments.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| live HubSpot portal → `scripts/role_vocabulary.py` | A credentialled read of every contact's `jobtitle` across the portal. Read-only, but it is a bulk read of employment data. |
| clustered titles → Anthropic Haiku | Portal job titles leave the portal for one clustering call. |
| committed cache → operator-facing menu | The YAML decides what an operator believes recurs in their CRM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-62-06 | Elevation of Privilege | `scripts/role_vocabulary.py` writing to the portal | high | mitigate | The script issues only `POST /crm/v3/objects/contacts/search` reads and never a PATCH/POST-to-object; `_portal_ok()` refuses with exit 1 and no API call on a portal mismatch, copied from `inventory_org_type_values.py`. |
| T-62-07 | Information Disclosure | job titles sent to Anthropic for clustering | medium | mitigate | Only distinct `jobtitle` STRINGS and their counts leave the portal — no names, emails, phones or record ids are placed in the clustering payload. Pinned by an acceptance criterion on the request-payload shape. |
| T-62-08 | Tampering | an un-evidenced list rendered as portal-derived | high | mitigate | `evidenced` is carried at both document and family level, `load_families()` returns it alongside the list rather than the list alone, and `offer_block` emits the disclosure sentence — all three pinned by tests in Task 2. |
| T-62-09 | Spoofing | the clustering model inventing a family no title supports | medium | mitigate | The system prompt forbids members that were not in the input; the emitted YAML carries each family's `members` so an invented family is visible in the committed artifact. |
| T-62-10 | Denial of Service (budget) | an unbounded portal sweep | low | accept | The sweep is paged, read-only and run manually by an operator, not on a schedule; HubSpot search reads are free and this repo already runs the identical idiom for `lv_org_type`. |
