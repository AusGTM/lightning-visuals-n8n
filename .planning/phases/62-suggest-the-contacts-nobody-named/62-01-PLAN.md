a single company with nobody at it, through eligibility, the sitemap ladder, the role filter, row
synthesis, and into `extraction.validate()` as a proposal.

(role vocabulary, pricing, provenance, the sitting itself) hangs off the row shape and the
decisions this module produces.

family), and a test file exercising the whole chain offline.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fetched page content → row synthesis | Page HTML and sitemap XML are attacker-influenceable. Names, titles and URLs read out of them are untrusted input crossing into a row that may become a HubSpot write. |
| sitemap-derived URL → `web_fetch` | A page can list any URL it likes; a candidate must pass scheme → host → budget before it is fetchable. |
