<objective>
Make `regions.aliases` the one country-name/ISO2 → region-code table in the system, delete the
hand-typed duplicate, and declare the HubSpot schema the widened whitelist needs.

Purpose: today every non-AU/NZ country collapses to `Other` in all three normalisers, so
plan 01's whitelist can never be reached by a newly-enriched US/GB/CA company. A second,
independently hand-typed name→ISO2 map (`_COUNTRY_ISO2`) already exists for phone
normalisation — this repo has hit the two-tables-drift bug class five times on this exact
surface, so the fix is one table, not two.

Output: a full `regions.aliases`, three normalisers reading it, `_COUNTRY_ISO2` deleted, a
superset parity test, and the HubSpot property manifest entries plan 05 pushes live.

</objective>
