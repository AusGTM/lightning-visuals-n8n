## Executor fallback (D-75-10, applies to EVERY task in this plan)

Each task names the exact command. The executor ATTEMPTS it. If the permission classifier
refuses the armed write from a subagent (the known-blocked line per the repo's own standing
note: disarmed deploys and API reads pass, ARMING writes do not), the executor STOPS at the
task's checkpoint, prints the identical command verbatim for the operator to run in their own
shell prefixed with `!`, waits, and then runs the read-back itself. A blocked attempt is a
checkpoint, never a silent skip and never a substituted weaker command.
