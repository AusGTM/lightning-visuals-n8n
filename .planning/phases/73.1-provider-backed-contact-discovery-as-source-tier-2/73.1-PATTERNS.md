**Email-domain gate to extend for emailless rows (D-16c)** — `partition_for_dispatch`
loop (`suggest_contacts.py:914-940`):
```python
def partition_for_dispatch(rows, company_domains):
    _, no_email_held = extraction.hold_emailless(rows)
    held_indices = {entry["index"] for entry in no_email_held}
    ...
    sendable = []
    held = list(no_email_held)
```

calling `email_domain_relation(row.get("email"), ...)`, add
`if not row.get("email"): sendable.append(row); continue` — copy this exact guard shape

### `operator-claude-plugin/scripts/extraction.py` (utility, transform)

**Analog:** itself — `hold_emailless` (`extraction.py:832-870`)

**Core pattern to relax (D-16b)**:
```python
def hold_emailless(rows: list) -> tuple:
    sendable: list = []
    held: list = []
    for i, row in enumerate(rows):
        if _present(row.get("email")):
            sendable.append(row)
        else:
```

— reuse the SAME `_present` predicate (already imported/defined in this module) for all
four fields, per the module's own stated discipline ("Presence is decided by `_present`
... so the two can never disagree").

**Core request-response pattern to copy verbatim in shape** (`backend_status.py:26-53`):
```python
STATUS_PATH = "webhook/hubspot/backend-status"
DEFAULT_TIMEOUT = 30

def status_target(config: dict) -> str:
    """The endpoint this module POSTs to. Never includes the secret."""
    return f"{str(config.get('n8n_url') or '').rstrip('/')}/{STATUS_PATH}"

def _unavailable(reason: str) -> dict:
    return {"available": False, "reason": reason, "data": None}

def fetch_backend_status(config: dict, transport=requests.post) -> dict:
    if not config.get("webhook_secret"):
        return _unavailable("webhook_secret_not_configured")
    headers = {"X-Enrichment-Secret": config["webhook_secret"]}
    try:
        response = transport(status_target(config), headers=headers, json={},
                             timeout=DEFAULT_TIMEOUT)
    except Exception:
        # Never echo the transport exception's text — it can carry request headers.
        return _unavailable("endpoint_unreachable")
```
For the discovery client: `DISCOVERY_PATH = "webhook/hubspot/suggest/discover"`,
`discovery_target(config)`, `fetch_discovery(config, body, transport=requests.post)`
posting `json={"run_id": ..., "companies": [...]}` (D-08) instead of `json={}`. Keep the
**never-echo-exception-text** rule and the `X-Enrichment-Secret` header convention
identically.

**Error handling pattern** (`backend_status.py`, continued): degrade to
`{"available": False, "reason": ..., "data": None}` shape on any failure — never raise,
never return a blank-but-successful mapping (D-08 rule cited in the docstring).

**Recovery/durable-path pattern** — reuse, do not reimplement:
`operator-claude-plugin/scripts/watch.py::recover_async_dispatch(config, run_id,
expected_chunk_count, *, workflow_id=None, workflow_name=None, echo_node=None,
