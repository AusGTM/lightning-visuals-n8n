<objective>
Attempt 2's Stage A CSV carried the same person three times — rows 37 and 38 repeating row 3, one
of them a case variant. Nothing collapsed them, so the batch reached HubSpot Create with a
duplicate email and took a 409. That 409 is what detonated F-A6.

Fix the input, in the plugin, before the send: cluster on the identity rule this codebase already
uses, keep the first occurrence exactly as written, tag the losers `duplicate_in_csv` naming the
winner, and show the collapse in the preview. First wins — no merge, no batch refusal, no second
dedupe in the backend.

Purpose: an operator's spreadsheet is the least trustworthy input this system takes, and it is the
one place a cheap exact-match collapse removes an entire failure class. Output: a deduped file
path the dispatch step sends, and a preview that says what was dropped.
</objective>
