Convert the remaining lanes — enrichment, review, the local variants — to the gated sentinel
mechanism, split the over-wide response Merge, make the contract a generation-time refusal, and
return the whole offline harness to green.

node type declares. Closing it in a test alone would leave the next generator change free to
re-create it, so the contract also becomes a refusal in the builder.

generation-time assertion, and a green harness.
