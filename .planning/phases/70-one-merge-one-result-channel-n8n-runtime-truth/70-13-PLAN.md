<objective>
Delete the self-referencing fan-out from the enrichment graph so the loop G-70-5 observed
cannot happen at all, refuse the request that used to trigger it, and make a self-dispatching
node a generation-time error rather than a runtime hazard.

Purpose: on 2026-09-10 the gap-closure enrichment body dispatched 135 child executions in six
minutes from four disarmed proof sends (12211–12348). `Dispatch Self` ran once per execution with
a marker item although its only declared producer emitted zero items, and its runData `source`
named a gate Code node that has no connection to it. The mechanism was not isolated. D-70-24's
ruling: only the ABSENCE of a self-referencing `Execute Workflow` node makes recursion impossible
on this engine.

Output: an enrichment graph with no `executeWorkflow` node, a refusal row for `scale_up: true`,
a generation-time refusal that keeps it that way, and an offline harness that asserts the
refusal instead of the deleted feature.
</objective>
