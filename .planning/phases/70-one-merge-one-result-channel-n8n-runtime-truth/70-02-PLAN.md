**Builder — three helpers, following `code_node`'s dict convention and
`splice_write_gates`'s mutation convention:**

- `merge_node(name, x, y, inputs=2, mode="append", combine_by=None)` — emits
  `type: "n8n-nodes-base.merge"` with the verified `typeVersion` and parameter keys. Docstring
  cites D-70-01, D-70-02 and research Pitfall 1, and states the obligation that every input must
  always fire.
- `splice_merge_before(nodes, conns, target_name)` — collects every inbound connection whose
  target is `target_name`, creates one Merge with that many inputs, re-points each collected
  edge to a DISTINCT Merge input index (preserving the current edge order so the walker's and
  n8n's input indices agree), and wires the Merge's single output to `target_name`. Returns the
  Merge node's name.
- `set_always_output_data(nodes, names)` — sets `alwaysOutputData: true` on each named node.
  It must REFUSE (raise) when asked to set it on a node of type `n8n-nodes-base.if`: n8n's own
  documentation warns this can loop, and an IF's placeholder item would leave on an output the
  builder does not control. Where a lane terminal is an IF output, insert a per-lane NoOp/Code
  terminal node on that branch and set the flag there instead.

**Ingest graph changes:**

   today. `Build Ingest Response` keeps running and keeps emitting its rows — it is now read
