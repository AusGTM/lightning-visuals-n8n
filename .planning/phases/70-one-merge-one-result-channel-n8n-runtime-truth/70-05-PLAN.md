<objective>
One canonical write request, one gate per lane, and a refusal that is a row rather than a silence.

Purpose: this is the phase's access-control layer. Today the gate accepts a row's identity through
a four-way fallback ladder that grew from two separate live incidents, drops every refused row on
the floor, and does not exist at all on the lane that carries the operator's real batches — where
the check is inlined in a decision node instead. After this plan the predicate has one input
shape, one home per lane, and a refused row reaches the operator with its reason attached.

Output: an IF-shaped gate on every gated write in every lane, reading one canonical shape, with a
build-time assertion that every gated node's upstream emits it.
</objective>
