<objective>
Retire the idiom completely: every remaining by-name node read goes, the carry mechanism replaces
it at every HTTP hop, the run-recovery module is deleted, and the builder refuses to generate a
workflow that reintroduces either.

by-name reads have been removed lane by lane; here the detector from 70-01 becomes a hard
assertion in `main()`, so the next plan's new gate and IF nodes are generated under it and no
future phase can quietly re-grow the pattern.

Output: an enrichment graph whose rows survive every HTTP hop on the row itself, a deleted
`n8n/code/nodeRunRecovery.js`, and a builder that fails loudly on a by-name read.
</objective>
