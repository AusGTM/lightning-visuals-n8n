  <action>
    Create `operator-claude-plugin/scripts/measure_dispatch.py` as a READ-ONLY measurement module.
    One thin path, wired end to end: config in, live execution history out, one comparison line
    printed.

    Three functions and a `__main__`:

    `executions_in_window(config, workflow_id, started_after, started_before, transport=..., limit=...)`
    — calls `executions_client.list_executions` for that workflow id, keeps only entries that are
    dicts carrying a `startedAt`, filters to the half-open window, returns them newest-first. Copy
    `find_latest_sj3_batch`'s sort/filter shape rather than re-deriving it. Never construct an
    arming call, never import `n8n_arming`; the only n8n calls this module may make are
    `list_executions` and `get_execution`.

    `passes_for_record(executions, record_key)` — given those executions and one record's id or
    domain, returns how many of them touched that record, as `{"count": int, "execution_ids": [...],
    "basis": "measured"}`. When the read raised, or the window returned nothing, return
    `{"count": None, ..., "basis": "unmeasured", "reason": "<why>"}`. `count` is `None` for an
    unread window — never `0`. Let `ExecutionsClientError` propagate out of `executions_in_window`;
    do not catch it into a return value (V7 — the same rule `ArmingRefused` follows).

    `compare_to_projection(measured, projection)` — takes the dict above and
    `write_grant.envelope(...)`'s figures dict for the same record set, returns
    `{"measured_executions", "projected_executions", "projection_basis", "delta", "verdict"}` where
    `verdict` is one of `matches`, `differs`, `unmeasured`. It reads
    `projection["projected_executions"]` and never recomputes the formula.

    `__main__`: accepts a workflow id, an ISO window, and one record key; prints the comparison as
    one line per figure with its basis word attached. This CLI is what Task 2 runs against live
    history.

    Write `operator-claude-plugin/tests/test_measure_dispatch.py` alongside: a fake `transport`
    returning a canned executions payload (no socket), covering — a window that contains two passes
    for one record, a window that contains one, a transport that raises (assert the error
    propagates, assert nothing returns `0`), and a `compare_to_projection` case where measured and
    projected disagree (assert `verdict == "differs"` and that both numbers survive into the result
    rather than one overwriting the other).
  </action>
