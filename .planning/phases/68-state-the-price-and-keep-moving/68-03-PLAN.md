<objective>
Close the phase's two remaining requirements: sweep every operator skill for disclosures that halt
but should not (FLOW-04/D-68-09), and re-state D-59-06's revoke semantics honestly now that consent
is implicit (FLOW-05).

Purpose: the audit's value is not the finding of new halts — plan 68-02 already converted the four
that mattered. Its value is the recorded verdict for every other line, so that a genuine decision
point cannot be swept away later by an agent applying "state, don't halt" too broadly, and so Phase
67 — which edits this same prose next — inherits a checked boundary rather than a judgement call.
And FLOW-05 exists because implicit consent moves where the honesty is owed: the operator's interrupt
is free only inside the pause, and every site that already tells the truth about a revoke must now
tell the same truth about the interrupt.

Output: the sharpened interrupt/revoke statement at four sites with its pin, and a disclosure-audit
ratchet whose module docstring carries the per-skill verdict table.
</objective>
