<objective>
Convert the halting ask into a stated line at every site it is written, by making the DEFAULT path
the one that already does not halt: with no grant open, the round prices a grant over exactly this
batch, states it, pauses, and opens it — then takes the granted branch that has always said "ask for
nothing here".

Purpose: D-68-01 chose the broad reading — approval is implicit on the no-grant branch too. D-68-03
makes that mechanically possible: `suggest_contacts.agreed_cap` raises `CapRefused` when no grant
priced a suggestion allowance, so a grant-less "proceed" would have no ceiling for the operator's
interrupt to land against. Opening the grant mints the envelope, so the line the operator reads is a
real number. Every mechanism already exists; this plan is prose plus one new prose-contract test.

Output: four converted default branches, the inline grant offer at each batch entry point, the pause
placed once per skill, and `test_implicit_approval_contract.py` pinning the call order, the refusal
behaviour and the unsampled-ceiling disclosure.
</objective>
