<objective>
Convert the phase's one genuinely unproven architectural claim into observed evidence, then
put the resulting scope decision to the operator.

Purpose: 58-RESEARCH.md traced through `build_cloud_workflows.py` that an unrecognized `mode`
key on a companies webhook event would ride the row spread all the way to
`Decide Company Action`, where `isReturnOnly(row.mode)` forces `action: "proposed"` before the
write-safety check runs. That trace is strong — `build_webhook_event`'s own docstring already
reasons from it — but it has never been observed on a live execution, and the phase's whole
"research without writing" path rests on it. Project memory is explicit that a stored
read-back proves nothing; only an execution's own runData does.

Output: a reusable probe script, a written verdict, and an operator decision on whether the
backend research node is extended to seek domains inside this phase.
</objective>
