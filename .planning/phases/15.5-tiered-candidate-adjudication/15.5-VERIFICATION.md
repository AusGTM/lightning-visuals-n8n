## Finding 1 (WARNING — test-rigor gap, not a functional defect)

**Location:** `tests/n8n/mergeCompanies.test.mjs`, test `"TA-4/TS-1/criterion-5: fresh vs stale page_age (recency) produce IDENTICAL canonicalPatch — recency changes ranking, changes nothing else"` (lines 168-181).

**What the plan asked for (Task 5f):** "Run the same research candidate through the merge twice, differing ONLY in synthetic page_age (fresh vs years-stale, hence very different composite scores) and assert the two canonicalPatch objects are IDENTICAL."

**What was actually shipped:**
```js
const freshMerge = mergeCompanies({}, candidate, undefined, { source: "claude_web", confidence: 90 });
const staleMerge = mergeCompanies({}, candidate, undefined, { source: "claude_web", confidence: 90 });
```
Both calls pass **byte-identical arguments** — `mergeCompanies` has no `page_age`/recency parameter at all (confirmed: `function mergeCompanies(existingProps, candidateRow, fieldPolicy, opts)`), and neither call's `opts` differs in any way. `wyong.page_age` is fetched from the fixture but explicitly discarded (`void wyong;`) with a comment acknowledging "recency/page_age never reaches mergeCompanies at all today." The assertion `assert.deepEqual(strip(freshMerge.canonicalPatch), strip(staleMerge.canonicalPatch))` is therefore a tautology — `f(x) === f(x)` for a pure function called with the exact same `x` twice — and provides **zero evidence** for the claim it is named for and listed against in the spec's Requirements→Test map (TA-4 row).

**Why this is not a BLOCKER:** the underlying invariant IS independently true, verified by direct source inspection in this report (D2-Safety Finding): `mergeCompanies.js` never reads recency/page_age/composite in any form, and the ONLY producer of `confidenceByField` in production (`scripts/build_cloud_workflows.py`'s Apply Judge Verdict wrapper) sources it exclusively from the judge verdict's own confidence, never the A/R/G/T composite. The immediately-following DELIBERATE-BREAK test in the same file (lines 194-220) DOES perform a substantive computation — it runs `scoreResearchCandidates` against the real Wyong fixture's stale `page_age`, derives a real composite (`0.674...`, asserted `< 0.80`), wires that composite into `confidenceByField`, and shows a previously-promoted field stops promoting. That test is legitimate evidence for the counterfactual (if you DID wire the composite in, it would break) but does not substitute for the missing positive proof (that the correct code, under genuinely varying page_age propagated through the real pipeline, produces identical output).

**Recommendation:** rewrite the "TA-4/TS-1/criterion-5" test to derive `confidenceByField` for the fresh and stale rows via the real production wiring (`scoreResearchCandidates` → simulated judge verdict → `judge_confidence_by_field`, which by construction never varies with page_age) rather than passing identical `opts` literals, so the test genuinely exercises the claim. Until then, this specific test should not be relied upon as proof of TS-1/TA-4 — rely on the structural analysis in this report and the DELIBERATE-BREAK test instead.
