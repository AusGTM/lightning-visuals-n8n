<objective>
Take the run off the synchronous response window. Submit returns a handle immediately, progress
is readable while the work runs, and an interrupted run resumes or fails loudly.

Purpose: RUN-01/03/04, absorbed from Phase 55 by D-61-08. Autonomy that still holds a connection
open for roughly 100 s per two-record chunk is not autonomy — a 40-record batch is twenty
sequential held connections, and a 300-record batch is not attemptable at all.

Output: an async run shape built on the substrate 61-01's operator decision selected, with the
n8n execution cost that decision was made on.

This plan is deliberately written against a verdict document rather than against assumptions.
Task 1 exists because the alternative — improvising a different mechanism mid-execution when a
premise turns out false — is how this phase's own risk register says it fails.
</objective>
