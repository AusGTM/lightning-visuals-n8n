<objective>
Decide what n8n Cloud's execution model actually permits for submit/poll/resume, BEFORE any
task is planned on top of it (D-61-08 carries Phase 55's spike-first warning verbatim).

run can outlive that window, where its state can live, and what a batch costs in executions
against a hard 2,500/month budget are all decided by the platform, not by our code. Planning
61-05 against an unknown execution model is how this phase fails.

Output: `61-SPIKE-VERDICT.md` — a verdict per question with an explicit basis word, and an
operator decision on run-state location.

This plan writes NO production code. Its deliverable is a decision document.
