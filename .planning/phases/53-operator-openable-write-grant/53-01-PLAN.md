<objective>
Make an operator-openable write grant real, end to end, on one record: an admin sets one key in
`operator.local.json`, the operator opens a grant in conversation, a dispatch arms under it, and the
window disarms as it does today. No shell environment variable is involved on the interactive path.

Purpose: G-2 is the milestone's blocker. `n8n_arming._arm_gate()` requires `ALLOW_N8N_ARM=true` in
the session's shell environment, which an operator in Claude Desktop cannot set, so the documented
operator path ends in a refusal only an admin with terminal access can clear. Every HubSpot write
this client has seen land was landed by an admin from a terminal. This plan moves the interactive
path's authority to a place an operator's own surface can actually satisfy, and leaves the headless
path's authority exactly where it is.

Output: `scripts/write_grant.py` (the grant object, its authority, open and close),
`n8n_arming._arm_gate` taking config and an optional grant, `tests/test_write_grant.py`, and one
deliberate re-point of the arm/probe parity pin.

Scope note: the envelope arithmetic, revocation, expiry and the two proposed guardrails are plan
53-02. The operator-facing config and confirmation surface is 53-03. Skills, docs and the release
are 53-04.
</objective>
