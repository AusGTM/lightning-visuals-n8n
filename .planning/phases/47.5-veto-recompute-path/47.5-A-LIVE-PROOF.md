## Task 2 — bounce (`n8n_control.set_active`, twice)

`deploy_n8n_workflows.py` never activates and `apply_mutation` refuses structural changes, so
neither can reload a newly-deployed graph. `set_active` is the named vehicle, and its verdict
comes from an INDEPENDENT second GET, never from the activate/deactivate call's own echo.

Driver (`config_gate.load_config()` — 47.5-RESEARCH.md's snippet calls `config_gate.load()`,
which does not exist; corrected here):

```

import sys; sys.path.insert(0,'operator-claude-plugin/scripts')
import config_gate, n8n_control
cfg = config_gate.load_config()
for want in (False, True):
    print(n8n_control.set_active('950HPb7a1GgSAIyZ', want, cfg))
"
```
