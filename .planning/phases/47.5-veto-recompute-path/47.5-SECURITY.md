## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| caller → n8n webhook | The D-18 POST body, header-authenticated (`X-Enrichment-Secret`) before any node runs | the `recompute`/`domain` intent — **request-level only, never a row property** |
| webhook row → HubSpot PATCH | `_writeSafetyAllows` plus the `TEST_RECORD_IDS`/`TEST_RECORD_DOMAINS` allowlist gate every write | write-authorization state |
| operator shell → n8n Public API | Two-key gate (`ALLOW_N8N_DEPLOY` + `DRY_RUN=false`) for deploy; `ALLOW_N8N_ARM` for arming | workflow JSON, arming literals |
| n8n running graph → HubSpot | Disarmed by default; an empty allowlist denies every write | company property PATCHes |
| public web → evidence file | Researched D-V6 claims, untrusted until cited with a URL | operating-presence verdicts |
| rubric change (both engines) → scored population | No record is written at decision time; effects land only on the next recompute | the veto predicate itself |
