<objective>
Build the recency rule the operator ruled for on 2026-09-12. It does not exist today in any
form: all three merge engines answer `needs_review` for ANY non-blank `stale_refreshable`
value, ignoring `stale_after_days` entirely, under a comment that reads "Refresh candidate
requires review in MVP." This is new logic, not a tweak.

Purpose: an eighteen-month-old job title is not evidence, and refusing to refresh it means the
CRM ages into wrongness while the waterfall keeps paying to discover the truth. D-72-06 scopes
the fix tightly — only `stale_refreshable` fields, only past their own TTL, only when the
provider observation is genuinely newer — so `fill_blank_only` and `manual_protected` keep
behaving exactly as they do now (the SAFE-01 line).

**Scope of the fetch, stated rather than implied.** D-72-07 names HubSpot's own property
history as the existing value's clock. That data is unavailable on the CRM search endpoint
every lookup in this repo uses; it needs a targeted `propertiesWithHistory` read against a
known object id. This plan wires that read on the INGEST CONTACTS lane, because that lane is
the one D-72-17 observes live at the end of this phase. The enrichment lane's contacts branch
and the companies branch do not get a history hop here — not because the work is hard, but
because nothing in this phase can verify them: there is no live gate on those lanes, and a
history hop nobody can observe is a hop nobody can trust. Their behaviour is unchanged by
construction, since an absent history means the gate takes the pre-72 `needs_review` branch.
Plan 07 files that as a `design` todo with the decision it needs. D-72-09's "companies inherit
it in this phase" is satisfied by the ENGINE change — `mergeCompanies.js` and the Python oracle
carry the identical predicate and their fixtures prove it — and company `industry` recency is
recorded as unobservable until that todo lands.

Output: a real TTL branch and a generalized system-correctable predicate in all three engines
under Phase 46 parity, an `opts.now` clock so the tests are deterministic, and one history hop
on the ingest lane joined by a carry Merge with a sentinel.
</objective>
