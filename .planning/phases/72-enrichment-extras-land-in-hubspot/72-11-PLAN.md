<objective>
Close gap G3 (D-72-09, review WR-02): Phase 72's new overflow-slot dedup compares candidate
values case-SENSITIVELY in both JS engines (`n8n/code/mergeContacts.js:352`,
`n8n/code/mergeCompanies.js:380`) and case-INSENSITIVELY in the Python oracle
(`src/merge_policy.py:188`, `route_overflow`). Two sources agreeing on a value that differs only
in case therefore manufacture a real overflow entry in JS and none in Python — a silent
divergence in a predicate the repo's Phase 46 rule treats as one contract across three engines,
and one neither suite exercises today.

**The rule chosen, and why: case-INSENSITIVE.** It is what the Python oracle already does, it is
what `has_conflict()` already does in all three engines (the convention this dedup was written to
mirror, per `route_overflow`'s own docstring), and it is right on the merits — the values this
helper is generic over are emails and URLs, which are case-insensitive in practice, while phone
values are already reduced to digits by normalization and are unaffected either way. Moving
Python to case-sensitive would instead contradict two existing conventions to satisfy one new
line.

All three engines change in ONE commit (Phase 46 parity rule).
Purpose: an overflow slot is a HubSpot write; a phantom one writes a duplicate value a human then
has to reconcile.
Output: the corrected predicate in both JS engines, a mixed-case fixture pinning it on both
sides, and the seven regenerated workflows that inline these modules.
</objective>

ranked candidate for it, not a member of a list.
**Decision: `no-change`.** The identity model was already decided and promoted in the original

(case-insensitive vs case-sensitive); it does not change what the primary key names or how many
slots exist.
**Invariant test, already accepted:** `tests/n8n/overflowSlots.test.mjs` and
`tests/test_merge_policy.py` pin "no `_3` slot ever" and "agreeing candidates never manufacture an
overflow"; Task 1 adds the mixed-case member of that same family. A future phase reintroducing a
list-shaped identity would go red there.
