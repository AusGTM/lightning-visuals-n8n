## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Letting an auditor (or yourself) self-author a corrected acceptance rationale | Twice this session an accepted risk turned out to rest on a premise a later change had destroyed (59's T-59-06) or on a control that never existed (50's T-50-11/27/36). Both times the auditor was explicitly forbidden to "fix" the rationale, and that refusal is the only reason the findings reached the operator instead of being smoothed into a clean CLOSED. | **blocking** | Surface the divergence, propose a disposition, and let the operator grant it. An accepted risk whose justification an auditor quietly repaired is worth less than an open one honestly labelled. |
| `close_phase_todos` retiring todos its phase never fixed | It matches on the `resolves_phase` frontmatter key alone and never checks whether the phase resolved anything. Phase 63 evaluated one todo's lever and **dropped** it; auto-closure would have silently retired an open `severity: major` defect. | **blocking** | Read the BODY of every pending todo carrying that `resolves_phase` before completing a phase. When one survives, strip the key and record why. |
| Trusting an edit instead of re-running the check | A `git add -A` aborted on an unrelated bad pathspec, so a todo was filed under `completed/` still asserting "Nothing about this has been fixed" — the rename committed, the content did not. Caught only by a post-commit `git show --stat`. | advisory | After any commit, run `git show --stat` and `git status --porcelain`. Git aborts the whole `add` on a pathspec error. |
| Assuming a workflow hook is off because config omits it | `nyquist_validation` and `security_enforcement` are BOTH absent from `.planning/config.json` and BOTH default to **enabled**. They were active and silently skipped for ~60 phases. gsd-core even ships a health rule naming this. | advisory | Both keys are now set explicitly. Check `gsd_run loop render-hooks verify:post --raw` against config before assuming a gate is inactive. |
